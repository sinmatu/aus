User Guide

This guide explains the normal working flow of the Asset Usage System: maintain asset definitions and profiles, record consumable usage and work, review records, then prepare monthly reports and exports.

Normal Workflow

Use the system in this order

AUS is asset-first. Usage and work are always recorded against a registered lorry or machine.
Sign in with an assigned active account Confirm the asset profile is correct Record fuel, battery, hydraulic, Rimula or other usage Record the work completed by the asset Review records and update review status Prepare and export monthly reports
Core rule: every usage or work record must belong to a registered asset. The asset is the main reference point throughout AUS.
01 · Roles

Manager and Staff

Only registered users with an approved role and active status may enter the system.

Staff

Staff handles daily operational entry, including Usage Entry, Work Entry, Records and Reports according to the access rules configured for the system.

Manager

Manager has the operational access plus Settings, asset configuration and review controls such as Mark Checked, Correct Entry, Correction Required and Void Entry.

Login rule: a valid Firebase login is not enough by itself. The account must also have an authorised role and status: active.
02 · Assets

Asset profiles are the centre of AUS

The Assets page shows registered lorries and machines with the metadata defined for their Asset Type.

Asset Type

Examples include Lorry, Machine, Excavator or other equipment categories defined by the Manager.

Asset Name / ID

The main operational identifier used in forms, Records and Reports.

Metadata

Profile fields such as Plate Number, Make / Model, Machine ID or other fields configured under Layer 1.

Assets page: this page is for profiles, not transaction history. Usage and work entries are kept in their own operational sections.

05 · Records & Review

Filter and review operational history

Records follows the same simple review pattern as the Lorry System, but uses Asset and record Type.

Filters

Select Month, Asset, record Type and sort order. Asset can be one specific asset or All Assets.

Bulk Review

Manager can select multiple reviewable records and use Mark Selected Checked when several entries have already been confirmed.

Review ActionMeaning
Mark CheckedConfirms that the record has been reviewed and accepted.
Correct EntryAllows an authorised correction to the individual record while retaining correction information.
Correction RequiredMarks an individual record as needing amendment or follow-up before it is considered final.
Void EntryMarks the record void so it can be excluded from normal operational reporting without treating it as an ordinary active record.
Bulk action: only Mark Checked should be performed in bulk. Correct Entry, Correction Required and Void Entry remain individual actions so each record is handled deliberately.

07 · Manager Settings

Layer 1 defines the system; Layer 2 creates the assets

Settings is Manager-only because these definitions control what appears throughout AUS forms and profiles.

Layer 1 · Asset Types

Define Asset Types such as Lorry or Machine. Each type has configurable metadata fields such as Plate Number, Make / Model or Machine ID.

Layer 1 · Usage Items

Define the consumables available in Usage Entry, such as Fuel, Battery, Hydraulic and Rimula.

Layer 1 · Units

Define measurement units such as drum, litre or pc.

Layer 1 · Work Measures

Define work measures such as hour, trip, km, load or tonne.

Layer 2 · Assets

Register the actual lorries and machines. Selecting an Asset Type automatically applies that type's metadata fields.

Edit, Do Not Delete

Layer 1 definitions can be edited by Manager. Existing definitions are retained rather than deleted so the system remains consistent with existing asset and record history.

Asset Type NameCan be edited separately.
Asset MetadataUse Edit Metadata to change fields such as Plate Number or Make / Model without changing the Asset Type name.
Usage ItemsCan be added or renamed.
UnitsCan be added or renamed.
Work MeasuresCan be added or renamed.
Before editing Layer 1: remember that these definitions are reused throughout the system. Use clear, stable names so existing assets and future entries remain easy to understand.
08 · Good Practice

Keep asset and usage records reliable

AUS is most useful when the master data and daily entries remain consistent.
Choose the correct asset before saving. Every Usage Entry and Work Entry is tied to that asset.
Use the configured units consistently. Avoid mixing units for the same type of consumption unless the business process requires it.
Enter actual work quantities. Reliable work data is necessary for meaningful usage-to-work comparison.
Use remarks when context matters. Replacement reasons, unusual usage or job references are useful during later review.
Use review actions instead of deleting history. Checked, Correction Required and Void statuses provide a clearer audit trail.
Review Reports before export. Confirm the Month and Asset scope first, especially when All Assets is selected.
